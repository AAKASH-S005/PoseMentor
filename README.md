# PoseMentor 💪
**AI-Powered Calisthenics Form Correction Application**

PoseMentor is a desktop-based AI application that uses **computer vision** to analyze calisthenics workouts and provide **real-time form correction feedback**.  
It is designed to help beginners and athletes improve technique, prevent injuries, and train smarter.

---

## 🚀 Key Features

- 🎯 Real-time pose detection using **MediaPipe**
- 🏋️ Supports multiple calisthenics exercises:
  - Pushups
  - Pullups
  - Parallel Dips
  - Bodyweight Squats
  - Plank
  - Hollow Body Hold
  - Superman Hold
  - Hanging Leg Raises
- 📷 Works with **front and side camera views**
- 💬 Beginner-friendly feedback for correct & incorrect form
- 🖥️ Clean and responsive **PyQt5 desktop UI**
- 🧠 Angle-based form analysis using OpenCV

---

## 🛠️ Tech Stack

- **Programming Language:** Python  
- **UI Framework:** PyQt5  
- **Computer Vision:** OpenCV  
- **Pose Estimation:** MediaPipe  
- **Numerical Processing:** NumPy  
- **Evaluation Utilities:** Scikit-learn
